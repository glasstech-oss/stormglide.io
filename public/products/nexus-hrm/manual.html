Section 01

Platform Overview

Stormglide HRM is a full-stack, cloud-native Human Resource Management System designed for mid-size organisations across West Africa. It consolidates every HR function — from hiring to exit — into a single, role-aware platform, accessible on desktop and mobile.

What problem does it solve? Most organisations in the region still manage HR through spreadsheets, WhatsApp chains, and disconnected paper records. Stormglide HRM replaces that fragmentation with structured workflows, audit trails, real-time visibility, and a consistent experience for every employee from day one to exit.

Built for Organisations of 20 – 200 People

The Business Tier is engineered for organisations that have outgrown spreadsheets but don't need — or want to pay for — an enterprise ERP. Every module is active from day one.

Role-First Architecture

Every screen, button, and data field is filtered by the logged-in user's role. A staff member never sees payroll. A manager sees only their direct reports. The MD sees everything.

Section 02

Dashboard & Analytics

High Complexity Real-Time Data Role-Filtered

The Dashboard is the first screen every user sees upon login. Rather than showing the same information to everyone, it renders a completely different interface depending on the user's role. A staff member sees their personal metrics; a manager sees their team's health; the MD sees the entire organisation at a glance.

Employee Personal Dashboard
Shows the employee's current leave balance, recent clock-in/out, pending action items from their inbox, personal KPI progress, and their journey phase within the appraisal cycle. Designed to answer "Where do I stand today?" at a single glance.
Manager Team Dashboard
Aggregates data for the manager's direct reports: who's in/out today, pending leave approvals, team performance scores, open KPIs, and flagged action items. Managers see only their own team, preserving data privacy between departments.
MD / Executive Dashboard
Organisation-wide view: total headcount, active leave count, attendance rate, top-performing departments, pending approvals at every stage, payroll summary, and performance distribution charts. Built for strategic oversight, not day-to-day operations.
Quick Actions
Role-appropriate shortcuts are surfaced on every dashboard — submit leave, clock in, initiate a review, view payslip, or access a direct report's profile — reducing navigation depth and improving daily adoption.
Performance Stat Cards
Key metrics rendered as visual cards with trend indicators. Each card is colour-coded by category — blue for operational data, orange for performance data — and supports drill-down to the underlying module for detail.
Greeting & Context Layer
Time-aware greeting personalised to the user's name and role. If the employee is currently on approved leave, an out-of-office banner is surfaced prominently. The system always reflects current real-world context, not stale snapshots.

Organisational impact: The dashboard removes the need for daily HR status calls, WhatsApp attendance pings, or spreadsheet-based reports. Decision-makers have live data without requesting it manually.

Section 03

Employee Management

High Complexity Core Module Foundation of All Other Modules

Employee Management is the structural backbone of the platform. Every other module references it. It stores the authoritative record of each employee — their identity, employment terms, reporting line, and documentation — and makes that data available across the system in a controlled, role-filtered way.

Employee Directory
A searchable, filterable list of all employees with profile photos, departments, roles, and contact info. HR and managers see the full directory; staff see a simplified version with contact info only. Advanced search by department, status, role, or join date.
Employee Profile
A structured profile for every employee containing: personal details, employment details (start date, contract type, job title, grade), compensation summary, direct manager, department, emergency contacts, and system account status. HR and above can edit; staff can view their own.
Document Vault
Secure document storage per employee — employment contracts, ID copies, academic certificates, appraisal records, disciplinary letters, and any HR-uploaded documents. Accessible to HR and above. Documents are categorised, timestamped, and tied to the employee's audit trail.
Reporting Line & Org Chart
Each employee is linked to a direct manager, creating a hierarchical reporting structure. This hierarchy governs who can approve whose leave, who conducts whose appraisal, and which data is visible on each manager's dashboard. Org structure changes propagate automatically.
Employment Status Tracking
Tracks whether an employee is active, on probation, on approved leave, suspended, or offboarded. Status changes trigger downstream effects — e.g., an offboarded employee loses system access; a leave-approved employee shows as out-of-office on team views.
Department & Position Management
Departments and job positions are configurable by HR Admin. Each position carries a grade or level that feeds into payroll bands and performance scoring templates. Restructuring a department re-maps all employees in it simultaneously.
Section 04

Leave Management

Medium Complexity Multi-Stage Approval Self-Service

Leave Management replaces email chains and paper leave forms with a structured, trackable, auditable workflow. Employees submit requests digitally; they are routed through the correct approval chain automatically based on the employee's reporting line; approved leave feeds directly into attendance and out-of-office indicators across the platform.

Leave Request Submission
Staff submit leave requests through the platform, selecting the leave type (annual, sick, maternity/paternity, emergency, study leave, etc.), specifying dates, attaching supporting documents where required, and providing a brief reason. The system prevents submission if the employee has insufficient balance.
Approval Workflow
Submitted requests route first to the employee's direct manager for initial approval, then to HR for final confirmation. Each approver receives an inbox notification. Any stage can return a request with comments. The full decision trail is logged for audit purposes.
Leave Balance Tracker
Each employee has a real-time leave balance per type, updated automatically when leave is approved and consumed. HR can manually adjust balances (e.g., for carry-over from a prior year). Employees always see exactly how many days remain before submitting.
Leave Types & Policies
Leave types are configurable by HR Admin. Each type has its own entitlement rules, carry-over policy, and whether supporting documentation is required. Changes to a leave type policy apply prospectively without disrupting historical records.
Team Leave Calendar
Managers and HR see a calendar view of approved and pending leave for their team, enabling them to identify conflicts before approving. Avoids situations where critical functions are unmanned simultaneously.
Out-of-Office Indicators
Approved leave automatically marks the employee as "Out of Office" across all platform views — their dashboard, the employee directory, and the manager's team view. This indicator is live and date-bounded; it clears automatically on their return date.
Section 05

Attendance & Time Tracking

Medium Complexity Hardware-Ready Web Clock-In

Attendance tracking captures when employees are present, records their working hours, and surfaces patterns to managers and HR. The system supports both web-based clock-in via the platform and integration with hardware devices (biometric, RFID), giving organisations flexibility in how they capture attendance without changing the reporting layer.

Web Clock In / Out
Employees can clock in and out directly through the platform on any device — desktop or mobile. Each event is timestamped, IP-logged, and linked to the employee record. No hardware dependency required.
Attendance History
A complete, chronological log of every clock event per employee. Filterable by day, week, or month. Displays clock-in time, clock-out time, total hours worked, and any flag (late, early-out, absent). Accessible to the employee, their manager, and HR.
Late & Absence Flagging
The system automatically flags late arrivals and unexplained absences against the configured work schedule. Repeated patterns generate alerts to the employee's manager. All flags are recorded and contribute to the performance module's attendance component.
Manager Team Visibility
Managers see a real-time view of who in their team is clocked in right now, who is absent, and who has left early. This view is scoped to direct reports only — managers cannot see other teams' data.
Leave & Attendance Integration
Approved leave days are automatically excluded from attendance reports, so an employee on annual leave is never flagged as absent. The integration is automatic — no manual reconciliation by HR is required.
Hardware Device Integration
For organisations using biometric or RFID time-attendance devices, the platform provides an integration layer to import device punch records. Device data syncs to the same attendance log, giving a unified report regardless of capture method.
Section 06

Payroll

High Complexity Sensitive Data HR Manager + Above Only

Payroll manages the end-to-end processing of employee compensation — from salary configuration through monthly run to payslip distribution. Given the sensitivity of compensation data, Payroll is one of the most access-controlled modules in the system. Staff see only their own payslip; nothing else.

Salary Configuration
Each employee has a salary record specifying base pay, grade band, allowances, and deduction rules. These are set by HR and updated when employment terms change. Salary history is retained for audit purposes and never deleted.
Monthly Payroll Run
HR processes the monthly payroll by running a calculation cycle that pulls from salary configuration, leave records, and any manual adjustments (bonuses, deductions). The run produces a payroll register showing total amounts per employee before finalisation.
Payslip Generation & Distribution
After payroll is finalised, individual payslips are generated and made available to each employee within their self-service portal. Payslips are date-stamped and archived permanently. HR can re-run or reissue payslips for any prior period.
Tax & Statutory Deductions
Configurable deduction rules for tax (PAYE, SSNIT, and other statutory deductions applicable in Ghana) are applied automatically during the payroll run. Rules can be updated as legislation changes without requiring a system upgrade.
Payroll Register & Audit Trail
A complete record of every payroll run — who was paid, what amount, which deductions were applied, and who processed the run — is stored permanently. Audit trail is tamper-resistant and available to authorised reviewers only.
Export for Accounting
The payroll register can be exported to standard formats for handoff to accounting software or the finance team. This eliminates manual data re-entry and associated transcription errors between HR and Finance.
Section 07

Performance & KPIs

High Complexity Target Cascading OKR-Ready

Performance Management aligns individual effort to organisational strategy by translating top-level goals into cascaded, measurable KPIs at every level of the organisation. It creates a visible link between what the MD defines as strategic priorities and what each individual is working toward — replacing ambiguous annual reviews with continuous, data-backed tracking.

KPI / Target Setting
Managers and HR can assign KPIs to employees or teams, specifying the objective, measurable target, deadline, and weighting. Employees can also propose their own objectives for manager approval. All targets are versioned — historical targets are preserved when updated.
Goal Cascading
Strategic objectives set at the MD level can cascade downward: MD goals → departmental targets → team goals → individual KPIs. This creates an unbroken line of sight from corporate strategy to daily individual work, making it clear to every employee how their role contributes.
Progress Tracking
KPI progress is updated by employees (self-reporting) and validated by managers. Progress bars, percentage completion, and status indicators (on-track, at-risk, missed) are visible on dashboards. Updates are timestamped for accountability.
Performance Scoring
At the end of a review cycle, each employee's KPI completion rate is aggregated into a performance score. Scores are weighted by KPI importance and feed directly into the Appraisals module as objective data, separating fact from subjective manager opinion.
Strategic Journey Tracker
Each employee's dashboard shows a visual journey panel — a three-step progress path indicating where they are in the current performance cycle (goal-setting, execution, review). This keeps every employee aware of their phase without needing to ask HR.
Executive Performance View
The MD and HR Manager have access to an organisation-wide performance heat map — visualising which departments are hitting targets, which are at-risk, and aggregate performance distribution. Enables data-driven resource allocation decisions.
Section 08

Appraisals

High Complexity Multi-Stage Review Packet-Based Sign-Off

Appraisals provide the formal, structured process for evaluating each employee's performance against their objectives, behaviours, and organisational contribution. The system guides the review cycle from self-assessment through manager review, alignment meeting, and final sign-off — producing a permanent, auditable appraisal record for each employee.

Self-Assessment
At the start of an appraisal cycle, employees complete a structured self-assessment — rating their own performance on each KPI, reflecting on achievements, identifying development areas, and providing context for any missed targets. Self-assessments are visible to the manager before their evaluation.
Manager Evaluation
Managers complete a parallel evaluation for each of their direct reports, scoring on the same rubric as the self-assessment. The system surfaces the employee's self-rating alongside the manager's score, highlighting significant gaps that should be addressed in the alignment meeting.
Appraisal Packet
All appraisal data — KPI scores, self-assessment, manager evaluation, comments, and development plans — is compiled into a single structured document (the Appraisal Packet). This packet serves as the formal record of the review and is archived permanently in the employee's document vault.
Calibration & Rating Scale
HR configures the rating scale (e.g., 1–5 or Exceptional / Meets Expectations / Below Expectations). Scores are anchored to behavioural descriptions, not left to individual interpretation. This ensures consistency of ratings across departments and managers.
Sign-Off Workflow
Completed appraisal packets are signed off by the employee, their manager, and HR in sequence. Each signature is digitally timestamped. No further edits are permitted after sign-off. If either party refuses to sign, the system records this with a mandatory reason.
Historical Appraisal Records
Every employee accumulates a complete archive of all past appraisals. HR and managers can compare current performance to prior years. This record is critical for promotion decisions, disciplinary processes, and staff development conversations.
Section 09

Recruitment

Medium Complexity ATS Lite Converts to Employee

Recruitment manages the end-to-end pipeline from vacancy creation to employee onboarding trigger. It provides structure to what is often an informal, ad-hoc process — giving HR and hiring managers a shared view of candidates, stages, and decisions without relying on email threads and spreadsheets.

Vacancy Creation
HR creates a vacancy specifying the role, department, required qualifications, salary band, and deadline. Vacancies can be internal (visible to existing staff only) or general. Each vacancy has a unique ID linked to all associated candidates.
Application Management
Candidate profiles are created and linked to the vacancy. Profile data includes personal info, CV/resume, qualification documents, and interview notes. Multiple candidates can be active across multiple vacancies simultaneously without data confusion.
Recruitment Pipeline
Each candidate moves through defined stages: Application Received → Screening → Interview → Assessment → Offer → Hired / Rejected. Hiring managers drag candidates between stages, and every stage transition is logged with the date and responsible user.
Interview Scheduling & Notes
Interviewers can log interview notes, ratings, and recommendations against each candidate. Notes are visible to all users with access to that vacancy, enabling panel coordination without separate email threads or meeting notes documents.
Offer Management
Once a candidate reaches the Offer stage, HR can generate a formal offer summary within the system, record the agreed terms, and track acceptance or negotiation status. Accepted offers trigger the onboarding workflow automatically.
Hire-to-Employee Conversion
When a candidate is hired, their profile data is converted directly into a new employee record in the Employee Management module. No data re-entry is required. The new employee's contract start date, position, and department are pre-populated from the recruitment record.
Section 10

Training & Development

Medium Complexity Individual & Team Plans

Training & Development ensures that learning initiatives are planned, tracked, and tied to employee records — not lost in email confirmations or paper attendance sheets. It links training completion to the performance module, creating a complete picture of each employee's development over time.

Training Plan Creation
HR and managers create training plans for individuals or entire teams. Each plan specifies the training objective, provider (internal or external), scheduled date, and expected duration. Plans are visible to both the employee and HR from creation.
Session Logging & Attendance
After a training session, HR logs the session record — confirming which employees attended, the actual duration, facilitator, and any materials distributed. Attendance is stored against each employee's training history permanently.
Training History per Employee
Every employee has a training history tab in their profile showing all completed and upcoming training. This record is used during appraisals to assess investment in development and during succession planning to identify capability gaps.
Certification Tracking
Training completions that result in a certification (regulatory, professional, or internal) can be recorded with the certification name, issuer, and expiry date. Expiry alerts notify HR before certifications lapse, preventing compliance breaches.
Training Needs Identification
Managers flag training needs directly from the performance module — when a KPI is consistently missed, the system prompts the manager to log a training need. These needs feed into the next planning cycle, creating a closed loop between performance gaps and development actions.
Training Reports
HR can generate reports showing training investment by department (hours, cost, headcount), completion rates, upcoming sessions, and certification expiry timelines. Useful for board reporting, budget planning, and regulatory compliance evidence.
Section 11

Offboarding

Medium Complexity Checklist-Driven Triggers System Deactivation

Offboarding manages the structured exit of an employee from the organisation — ensuring nothing is missed, assets are recovered, knowledge is transferred, and the employee's system access is properly deactivated. It transforms an often chaotic, last-minute process into a managed, auditable sequence of tasks.

Exit Initiation
HR initiates the offboarding process by logging the departure — specifying departure date, reason (resignation, redundancy, retirement, contract end), and assigning the offboarding checklist. This creates the formal exit record and starts the countdown to system deactivation.
Offboarding Checklist
A configurable checklist of tasks is assigned on exit initiation — items like laptop return, key/card collection, knowledge transfer completion, final payroll confirmation, and benefits termination. Each item is checked off by the responsible party with a timestamp.
Asset Return Tracking
Company assets assigned to the employee (equipment, access cards, vehicles, tools) are listed and their return status tracked. Outstanding assets remain flagged until confirmed returned, preventing losses being overlooked in a rushed exit.
Exit Interview
HR can record the exit interview outcome — noting reasons for departure, satisfaction scores, and any feedback the departing employee provides. Exit interview data is aggregated over time to identify retention risk patterns at the departmental level.
Final Payroll Coordination
The offboarding record links to the payroll module to flag that a final settlement run is required. HR can mark the final payroll as processed and attach the settlement summary to the employee's departure record.
Record Archiving & Access Deactivation
On the departure date, the system automatically deactivates the employee's login access and marks their record as archived. Their data is retained for the legally required retention period. HR can retrieve archived records at any time for reference or legal purposes.
Section 12

Inbox & Notifications

Low-Medium Complexity Real-Time Alerts Action-Required Items

The Inbox is the platform's internal communication and action layer. Every event that requires a user's attention — a leave request waiting for approval, an appraisal pending sign-off, an onboarding task overdue — surfaces here as a structured notification, not as a separate email. It is the platform's answer to WhatsApp groups and email chains.

Action Inbox
Items that require a response (leave approvals, appraisal sign-offs, onboarding tasks, training confirmations) appear as action cards. Each card shows the source, the required action, the deadline, and a direct link to the relevant module. Actioned items are removed from the queue automatically.
System Notifications
Informational notifications (payslip ready, leave approved, KPI updated, appraisal cycle opened) appear as read-only items. These do not require action but keep users informed of changes that affect them, reducing the need to chase HR for status updates.
Unread Indicators
The Inbox icon in the navigation bar displays a live unread count. On mobile, this provides an at-a-glance alert that draws attention to pending actions without requiring the user to navigate into the module.
Priority Tagging
Certain events are automatically prioritised in the inbox — overdue approvals, approaching appraisal deadlines, and expired certifications are surfaced at the top of the queue regardless of arrival time, ensuring critical items are not buried under routine notifications.
Section 13

IT Administration & Settings

High Complexity IT Manager + Above System Configuration

The IT Administration module controls how the platform is configured, who has access to what, and how the organisation's identity is represented across the system. It is the control panel for all technical and governance settings — from user provisioning to branding to system health monitoring.

User Account Management
IT Admin creates, modifies, and deactivates user accounts. Account creation requires linking to an employee record. Role assignment determines what the user sees throughout the platform. Accounts can be temporarily suspended without deleting the employee record.
Role & Permission Configuration
The system operates on a seven-level role hierarchy. IT Admin can assign roles to users and configure which roles have access to sensitive modules (e.g., Payroll visibility). This configuration is audited — every role change is logged with the authorising user and timestamp.
Employee ID Card Generation
Branded employee ID cards are generated from within the platform — available in both vertical and horizontal formats. Cards pull from the employee's profile (name, photo, department, ID number) and the organisation's branding. Bulk printing is supported for onboarding cohorts.
Organisation Profile & Branding
The organisation's name, logo, address, and brand colours are configured here. These settings propagate to ID cards, payslips, appraisal packets, and all generated documents — ensuring a consistent branded experience throughout.
System Settings
Work week configuration, public holiday calendar, time zone, default leave policies, and approval workflow rules are all configurable without code changes. This makes the platform adaptable to different operational contexts without requiring a developer.
Audit Logs
A complete, tamper-resistant log of all sensitive actions across the platform — who logged in, who edited a salary record, who approved a leave request, who changed a role. Audit logs are available to IT Admin and above and can be exported for compliance reporting.
Section 14

Onboarding

Medium Complexity Checklist-Driven Linked to Recruitment

Onboarding manages the structured introduction of a new employee into the organisation — from the moment they accept an offer to the day they are fully operational. A good onboarding experience significantly reduces early attrition and time-to-productivity. Stormglide automates the task assignment and tracking so nothing falls through the cracks.

Onboarding Checklist
A configurable checklist of tasks is automatically assigned when a new hire is created — items such as IT account setup, workstation preparation, induction scheduling, policy acknowledgements, and HR document collection. Each task is assigned to a responsible owner with a due date.
Pre-Boarding Access
New employees can be granted limited system access before their start date to complete forms, sign documents, and review company policies. This reduces the administrative burden on their first day and allows them to arrive prepared.
Document Collection
HR specifies which documents the new employee must submit — national ID, academic certificates, tax forms, bank details, and employment contract signature. Submission status is tracked against each required document and HR is notified on completion.
Induction Scheduling
Orientation and induction sessions are logged in the onboarding record, linked to the training module. The new hire's attendance is confirmed once sessions are completed, closing the induction task automatically.
Recruitment-to-Employee Link
When a candidate is hired through the Recruitment module, their onboarding checklist is triggered automatically. All candidate data — name, role, department, start date — is pre-populated, eliminating re-entry and ensuring the process begins without delay.
Progress Tracking
HR and the new employee's manager can see the real-time completion status of all onboarding tasks. Outstanding items are flagged and can trigger reminders. The onboarding record is archived to the employee's profile once all tasks are complete.
Section 15

Organisation & People Tools

Medium Complexity HR Officer + Structure & Governance

This group of tools manages the formal structure of the organisation and the HR governance processes that affect employees throughout their tenure — from how the company is structured, to how it communicates, to how it handles sensitive people matters such as discipline, probation, and promotion.

Announcements
HR and Management can publish organisation-wide announcements directly within the platform — removing the need for mass emails or WhatsApp broadcasts. Announcements appear on employee dashboards, are date-stamped, and remain accessible in a searchable archive. Read receipts track who has acknowledged critical notices.
Department Management
HR configures and maintains the organisation's department structure — creating, renaming, merging, or archiving departments. Each department has a defined head, a parent department (for nested structures), and a list of active positions. All employee records are linked to a department, so structural changes propagate automatically.
Organisation Chart
A live, interactive visualisation of the organisation's reporting structure drawn from the employee records and department configuration. The org chart updates in real time as reporting lines change. Available to HR, IT, and the MD. Exportable as an image for board packs or operational documents.
Policies Library
A centralised repository of company policies — HR, finance, IT security, code of conduct, health and safety, and any other formal policy document. Policies are version-controlled: new versions replace old ones without deleting the history. Employees can access relevant policies from their dashboard and HR can track acknowledgement.
Disciplinary Management
HR logs formal disciplinary cases — specifying the nature of the complaint, the employee involved, the hearing date, the outcome (verbal warning, written warning, final warning, dismissal), and any appeal. Cases are linked to the employee's record and flagged during appraisal reviews. Confidentiality controls limit visibility to HR and above.
Probation Tracking
New employees on probation are flagged in the system with their probation end date. The platform automatically alerts the line manager and HR ahead of the review deadline. The outcome — confirmed, extended, or terminated — is recorded and the employee's status updated accordingly. Probation records are retained in the employment history.
Promotions Workflow
Managers can initiate a promotion request for a direct report — specifying the proposed new role, grade, and effective date. The request routes through HR review and MD approval. Once approved, the employee's profile, title, department, and salary band are updated simultaneously. A complete promotion history is maintained per employee.
Section 16

Operations Management

Medium Complexity IT Admin + HR Assets & Scheduling

Operations Management covers the day-to-day administrative functions that keep the organisation running — managing company assets, tracking access cards, configuring the work calendar, and handling internal support requests. These tools reduce the operational overhead on HR and IT by giving them structured, trackable workflows.

Asset Management
Company assets (laptops, mobile phones, vehicles, furniture, equipment) are registered in the system and assigned to employees. Assignment records include issue date, expected return date, and condition. When an employee is offboarded, outstanding assets appear automatically on the exit checklist. Unrecovered assets remain flagged until resolved.
Card Lifecycle Management
Access cards, ID cards, and building passes are tracked from issuance through to deactivation. IT Admin records each card's assignment, status (active, lost, deactivated), and return date. Lost cards are flagged for immediate deactivation. Card history is retained per employee for security audit purposes.
IT Registries
A registry of IT assets and system accounts — hardware serial numbers, software licences, access credentials managed by IT, and device assignments. Provides IT Admin with a single source of truth for all technology resources across the organisation, accessible without leaving the HR platform.
Internal Support Tickets
Employees can raise internal support requests directly within the platform — IT issues, HR queries, facilities requests, or administrative help. Tickets are routed to the appropriate team, tracked through to resolution, and closed with a response log. Reduces unstructured WhatsApp and email support channels.
Holidays & Work Calendar
HR configures the organisation's official public holiday calendar and work week (days, hours). Public holidays are automatically excluded from leave calculations and attendance reports. The calendar is shared across all modules that depend on working-day logic — leave balances, attendance flags, and probation countdowns all reference it.
Section 17

Advanced Performance Suite

High Complexity Manager + HR + MD Beyond Annual Reviews

The Advanced Performance Suite extends the core KPI and Appraisals modules with tools designed for continuous performance management — replacing the once-a-year review cycle with ongoing conversations, multi-directional feedback, data-driven calibration, and predictive insights that surface issues before they become problems.

Continuous Check-Ins
Structured, lightweight 1-on-1 conversations between a manager and each direct report are logged in the system on a regular cadence (weekly, fortnightly, or monthly). Each check-in captures talking points, agreed actions, and a sentiment indicator. The history of check-ins feeds into the formal appraisal as supporting evidence, reducing recency bias.
360° Feedback
Employees receive structured feedback from multiple directions — peers, direct reports, and stakeholders — not just their line manager. HR configures the feedback questionnaire and the rater pool. Responses are anonymised before the subject sees them. Aggregated 360° scores are incorporated into appraisal packets as a multi-rater dimension.
Performance Calibration
At the close of each appraisal cycle, HR and senior managers convene a calibration process — reviewing all ratings side by side to ensure consistency across departments and managers. The calibration tool surfaces statistical distribution of ratings, flags outliers, and allows bulk adjustments with a justification trail, preventing both grade inflation and unfair deflation.
Operations Cockpit
A consolidated command view for managers — showing team attendance status, open leave requests, KPI red flags, overdue check-ins, and pending appraisal actions all in one screen. Designed to give a manager everything they need to run their team effectively in a single glance, without navigating between modules.
Predictive Analytics
Available to HR and the MD, Predictive Analytics surfaces data-driven risk signals — employees showing early indicators of disengagement (declining attendance, falling KPI scores, no recent check-ins), departments trending toward performance issues, and headcount projections based on historical attrition. Moves HR from reactive to proactive.
Executive Sign-Off
After calibration, completed appraisal packets are routed to senior leadership for final sign-off before they are shared with employees. This ensures that sensitive performance decisions — particularly around ratings that affect bonuses or promotion eligibility — are reviewed at the executive level before being communicated downward.
Section 18

Finance & Expenses

Medium Complexity All Staff + Finance / MD

The Finance module covers two distinct layers: the personal financial view for all employees (payslip access, tax summaries, deduction breakdowns) and the expense management workflow for employees who incur costs on behalf of the organisation. Together, they give every employee visibility of their compensation and a structured path for reimbursement claims.

Personal Finance Dashboard
Each employee has a personal finance view showing their current salary, month-to-date deductions, tax contributions (PAYE, SSNIT), net pay, and year-to-date earnings. All figures pull directly from the payroll module. Employees never need to request this information from HR — it is always available self-service.
Payslip Archive
Every payslip ever generated for the employee is stored in their Finance section. Payslips are downloadable as PDFs. Employees can access historical payslips for tax filing, loan applications, visa purposes, or any personal financial need without contacting HR.
Expense Claims
Employees submit expense reimbursement claims for costs incurred on company business — travel, accommodation, client entertainment, supplies. Each claim includes the amount, category, date, and a receipt upload. Claims route to the employee's manager for approval and then to Finance for processing.
Expense Approval Workflow
Submitted expenses follow a structured approval chain: line manager first, then Finance or HR Manager. Rejected claims are returned with a reason. Approved claims are queued for payment processing and linked to the next payroll cycle or processed as an out-of-cycle payment per the organisation's policy.
Expense Reporting
Finance and the MD have access to expense reports by employee, department, category, and period. This provides visibility into discretionary spend, supports budget monitoring, and produces the data needed for quarterly financial reviews without manual consolidation from receipts.
Section 19

Enterprise Suite

High Complexity MD Only Strategic Governance

The Enterprise Suite is the MD-level layer of the platform — providing governance tools, strategic oversight capabilities, and system-wide controls that sit above day-to-day HR operations. It is designed for the Managing Director and senior leadership to govern the organisation, set strategic direction, and maintain brand and operational standards across the system.

Governance & Branding Console
The MD controls the organisation's identity within the platform — company name, logo, brand colours, and the subtitle that appears throughout the system. These settings propagate to all generated documents (payslips, ID cards, appraisal packets) ensuring brand consistency without involving IT on every update.
Strategic KPI Cascade
The MD sets top-level organisational objectives that cascade downward through the performance module. This creates a direct, visible link from the MD's strategic priorities to individual employee KPIs across every department. The MD dashboard shows real-time progress against each strategic objective.
Organisation-Wide Analytics
Exclusive executive analytics covering headcount trends, department performance distributions, leave utilisation rates, payroll cost summaries, attrition indicators, and appraisal score distributions. Presented in a visual format suitable for board reporting, with the ability to drill into department-level data on demand.
Final Approval Authority
Certain high-stakes decisions — executive appraisal sign-offs, promotion approvals above a defined grade, and policy changes — are routed to the MD for final authorisation. This ensures the MD maintains oversight of decisions that affect the organisation's structure, culture, or financial commitments without being involved in routine operations.
Compliance Oversight
The MD has read access to all audit logs, compliance records, certification expiries, and outstanding policy acknowledgements across the organisation. This view supports the MD's governance obligations — ensuring that the organisation can demonstrate compliance to regulators, auditors, or the board without assembling evidence from multiple departments.

Section 21

How the Modules Connect

The value of Stormglide HRM is not in each module in isolation — it is in how they form a single, interconnected system. Data entered once in one module propagates intelligently throughout the platform, eliminating re-entry, reducing errors, and creating a coherent picture of each employee's entire lifecycle.

Originating Module Connected Module(s) What Happens Automatically
Recruitment Employee Management Hired candidate converts to a new employee record. All profile data — name, role, department, start date — is pre-populated. No duplicate data entry.
Leave (Approval) Attendance Approved leave days are excluded from attendance reports. The employee will never show as absent during their authorised leave period.
Leave (Approval) Dashboard / Directory Approved leave triggers an "Out of Office" indicator on all platform views where the employee appears — their profile, the manager's team view, and the org directory.
Performance / KPIs Appraisals KPI scores at the end of a performance cycle are pulled directly into the appraisal packet as objective data. No manual transfer of ratings required.
Appraisals Employee Profile Finalised appraisal packets are archived in the employee's Document Vault. The employee's performance rating history is visible to HR and the MD across all past cycles.
Training Performance / KPIs Missed KPIs can trigger a training need flag. Completed training is visible alongside performance records in the employee profile, supporting development plan conversations.
Offboarding Payroll Exit initiation flags HR to process a final payroll settlement. The departure date is used to calculate pro-rated entitlements automatically.
Offboarding IT Administration On the departure date, the employee's system account is automatically deactivated. No manual IT action required to revoke access.
Any Action Inbox Any event requiring a user's response — leave approval, appraisal sign-off, task completion — generates an inbox notification for the relevant user automatically.
Employee Management All Modules The employee record is the anchor for every module. Changing a reporting line, department, or status cascades through leave approvals, dashboard views, and performance assignments without manual reconfiguration.
Section 22

Infrastructure & Hosting

Stormglide HRM is a fully managed, cloud-native application. The client organisation requires no servers, no IT infrastructure, and no database management. Stormglide manages and maintains all technical layers on behalf of the client.

Frontend
Global CDN Hosting
The web application is distributed via a globally replicated content delivery network, ensuring low-latency access from Ghana and across West Africa. Served over HTTPS with automatic SSL certificate management.
Backend API
Auto-Scaling Cloud Server
The application server scales automatically under load. JWT-based authentication with short-lived access tokens (1 hour) and 24-hour refresh tokens ensures secure, seamless sessions across all devices.
Database
Managed PostgreSQL
A fully managed relational database with automated daily backups, point-in-time recovery, and high-availability replication. Data is encrypted at rest. No database administration required from the client.
Security
TLS · JWT · RBAC
All data in transit is encrypted via TLS 1.3. Role-Based Access Control (RBAC) is enforced at the API layer — not just the UI. Even if a user bypassed the interface, the server would reject any request not authorised by their role.
Uptime
99.5% SLA Target
Platform availability is monitored continuously. Planned maintenance windows are communicated in advance. Unplanned downtime triggers automatic alerts to the Stormglide operations team for immediate response.
Backups
Daily Automated Backups
All client data is backed up daily with a 30-day retention window. Backup restoration can be performed by Stormglide within the SLA response time. Data can also be exported on request at any time.
